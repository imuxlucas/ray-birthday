# A little sunshine, for Ray

为 Ray 制作的生日动画，使用 p5.js / WebGL。画布随浏览器窗口自由调整比例，画面内容按可用高度等比例缩放并居中。

- 头像光源、丝线聚光灯、生日蛋糕与碰撞爱心粒子。
- 每批随机发射 1–9 条「人名 ♡ ray」，沿对应头像最近的光丝飞行，使用纤细的 Georgia 字体。
- 光斑沿蛋糕前半圈左右往返，淡雾强度为原来的 60%，边缘模糊过渡为原来的 20%。
- 本地合成的音乐盒生日旋律；若浏览器阻止自动播放，点击画面后启动。
- 页面为黑色沉浸式展示，空格键暂停或继续。
- 所有运行依赖及头像素材随仓库提供，无需构建。
